Call Chain 可视化组件对比

同一份调用链数据，三种不同的渲染方式

D3 Tree (Reingold-Tilford)
D3 v7 + 本地 static Zoom/Pan: d3-zoom 轻量，无额外依赖
优点
  • D3 项目已有，无需额外 CDN
  • 经典的树形布局算法
  • 样式完全可控
  • 支持折叠/展开交互
缺点
  • 仅支持树形结构
  • 需要手写布局代码
  • 大数据量需做虚拟滚动
  • 无法展示多父节点
ECharts Tree Series
CDN: echarts.min.js Zoom/Pan: 内置 roam 多种布局切换
优点
  • 内置滚轮缩放拖拽
  • 支持径向/正交/自上而下布局
  • 节点可折叠，样式丰富
  • 大数据量性能优秀
缺点
  • 仅支持树形结构
  • 库体积较大 ~1MB
  • 无法展示多父节点
  • 配置项较多
Dagre-D3
CDN: dagre-d3 + d3 Zoom/Pan: d3-zoom 支持 DAG 多父节点
优点
  • 支持 DAG 图（多父节点）
  • 自定义节点形状和 HTML
  • 有向图布局自动优化
  • 最适合复杂调用链
缺点
  • 需要手动引入 d3 + d3-zoom
  • 样式需手写 CSS
  • 折叠交互需自行实现
  • 学习曲线稍陡

    Presets:

    Overview（总览）

    展示当前仓库的知识图谱统计数据，包括文件数、类数、方法数等，以及各类关系（调用、导入等）的数量分布。

    Symbol Search（符号搜索）

    按关键字搜索代码库中的所有符号（类、方法、字段、文件等）。点击搜索结果可查看详情，包括调用者（Callers）、被调用者（Callees）和导入信息（Imports）。

    Browse All（全量浏览）

    无需搜索即可浏览所有符号。支持按类型切换（Classes / Interfaces / Methods / Fields / Files），并提供关键字过滤和分页浏览功能。点击任意符号可查看详情。

    Cypher Editor（Cypher 查询编辑器）

    直接编写和执行 Cypher 图数据库查询。上方提供Query Builder（通过选择框组合条件自动生成查询语句）和Presets（常用预设查询一键填入）。支持 Ctrl+Enter 快捷执行。

    常用查询模式：

    • MATCH (n:Class) RETURN n.name, n.filePath — 列出所有类
    • MATCH (n:Class)-[r:CodeRelation]->(m) RETURN n.name, m.name, r.type — 查询调用关系
    • MATCH (n:Method) WHERE n.name CONTAINS 'Service' RETURN n.name, n.filePath — 按名称过滤

    Impact Analysis（影响分析）

    输入目标符号名，选择分析方向（上游调用者 / 下游被调用者）和最大深度，BFS 遍历知识图谱以评估变更影响范围。结果按深度分级显示：WILL BREAK（直接影响）→ LIKELY AFFECTED（可能影响）→ MAY NEED TESTING（需测试）。

    前端页面映射

    扫描前端源码（.vue、.js、.ts）中的 API 调用（axios / fetch / http.request），与后端 HTTP 端点进行匹配，并关联到数据库表。支持：

    • axios.get('/api/xxx')、axios.post('/api/xxx', data)
    • http.request('GET', '/api/xxx')
    • fetch('/api/xxx')
    • 模板字符串：axios.get(\`/api/user/\${id}\`) — 通过参数模式匹配

    输入前端项目源码路径后点击"Scan & Match"，系统将展示前端页面 → API 调用 → 后端 Controller → Service → 数据库表的完整链路。

    其他提示

    • 页面顶部的仓库选择器可在已索引仓库之间切换，切换后自动刷新当前页面数据。
    • 所有操作结果以列表或表格形式展示，支持点击查看详情。
    • 查询结果过大时请使用分页或添加过滤条件。
